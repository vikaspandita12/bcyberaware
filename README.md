## About

BCyberAware is an AI-powered Threat Intelligence Dashboard designed to help individuals and organisations stay informed about the latest cybersecurity threats, vulnerabilities, and best practices.

## Features

- Real-time threat intelligence from **55 sources** — government CERTs (CISA KEV, CERT-In, CERT-EU, NCSC UK, JPCERT/CC, CCCS Canada, CERT-FR, CIS), NVD, GitHub Security Advisories (GHSA, with Atom fallback when the API rate-limits), ZDI 0-day pipeline, vendor PSIRTs (Cisco, Palo Alto, FortiGuard, Microsoft), elite threat labs (CrowdStrike, Mandiant, Unit 42, Talos, Check Point, Sophos X-Ops, Rapid7, Project Zero, Securelist, ESET, SentinelLABS, watchTowr, Tenable), and 20+ global/Indian security newsrooms. Sources refresh on a rotating priority schedule so the Worker stays under Cloudflare's 50-subrequest cap and no source is permanently DOWN
- **🎯 FIRST.org EPSS & CVSS Enrichment** — every CVE-bearing advisory is enriched in real time with its 30-day Exploit Prediction Scoring System (EPSS %) probability and percentile, plus CVSS base score and **⚔️ MITRE ATT&CK** technique tags
- **● DEFCON Cyber Posture Indicator** — live global posture level in the top bar computed from active exploitation, critical CVE volume, and high-EPSS vulnerabilities
- **🔎 Instant Command Search (`/`, `⌘K`), 7-Day Velocity Chart & Ecosystem Matrix** — filter across all advisories, exploits, news, and social intel at once; click any vendor pill or top-EPSS CVE to filter; sort by Severity, EPSS Risk, or Newest; export any view to **CSV**, **JSON**, or **OASIS STIX 2.1** (OpenCTI / MISP / TAXII / SIEM compatible)
- **🧬 Knowledge Graph (OpenCTI ideas, native)** — live MITRE ATT&CK heat matrix, vendor↔CVE↔technique↔actor relationship graph, actor/malware encyclopedia, Diamond Model counts, and an IOC hunt strip. No OpenCTI server — same Cloudflare Worker site
- **★ Analyst Watchlist & One-Click 🛡️ AI Triage** — pin advisories to a persistent local watchlist or click **🛡️ AI Triage** on any card to send it straight into the AI Threat Analyst for root-cause, hunting IOCs, and remediation steps
- **💬 Social Intel** tab — what the security community is posting right now on infosec.exchange (Mastodon), the `#cybersecurity` fediverse tag, Bluesky (verified security researcher feeds), Hacker News and r/netsec
- **🤖 AI Situation Summary** — a 3-bullet executive brief of the current threat picture, regenerated by Workers AI each time the feed refreshes
- **🕵️ Dark Web Early Warning** — live ransomware victim claims (`ransomware.live` RSS), 30+ tracked ransomware groups (`data.ransomware.live`), public breaches (`HaveIBeenPwned`), and active botnet C2 servers (`abuse.ch Feodo Tracker` + `Cybercrime Tracker`)

- **🔔 No-login alerts & 📡 RSS** — a `🔔 Alerts` toggle fires browser notifications for new CRITICAL / exploited-in-the-wild threats (polled every 10 min while a tab is open; nothing stored server-side, no account, no email), and `/feed.xml` serves the full live feed as RSS 2.0 for any feed reader

> **Why no X/Twitter?** The X API no longer offers a free read tier, so there is no cost-free, reliable way to pull posts. Mastodon and Bluesky expose public, key-less APIs and are where most of the infosec community now posts in real time.

## AI Threat Analyst (free)

The floating **🛡️ Ask Threat Analyst** chat runs on [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/) — no API key, no third-party account. The free Workers plan includes **10,000 neurons/day** (roughly a few hundred chats with the default model). The assistant is grounded in the live feed snapshot, so it can answer "what's exploited in the wild right now?" from the dashboard's own data.

- Endpoint: `POST /api/chat` (streaming SSE) — see `functions/_shared/chat-core.js`
- Situation summary: `GET /api/proxy?action=brief` — cached per feed refresh (≈12 AI calls/day), so it costs almost nothing from the free quota
- Model: set `AI_MODEL` in `wrangler.jsonc` (default `@cf/meta/llama-3.1-8b-instruct-fast`; `@cf/meta/llama-3.3-70b-instruct-fp8-fast` for higher quality at ~6× the neuron cost)
- Guards: per-IP rate limit (20 msgs / 10 min), 1,200-char messages, 8-turn history, cybersecurity-only system prompt
- If the deploy fails on the `ai` binding, make sure the `CLOUDFLARE_API_TOKEN` has **Workers AI → Edit** permission

## Development

The dashboard UI lives in `src/app.jsx` and is precompiled to `app.js` (served as a static asset — no in-browser Babel).

```bash
npm install        # one-time setup
npm run build      # compile src/app.jsx → app.js (run after editing the UI)
npm run dev        # build + local server at http://localhost:8787
npm run deploy     # build + deploy to Cloudflare
```

> **Note:** after editing `src/app.jsx`, run `npm run build` and commit the regenerated `app.js` — the GitHub Action deploys files as-is.
